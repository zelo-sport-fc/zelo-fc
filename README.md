# Zelo Sport — Web3 Sports Prediction Mini App

## Overview
Zelo Sport brings the excitement of football predictions directly into Telegram, making Web3 simple and engaging for everyday sports fans. By combining a smooth, interactive user experience with real-time sports updates, users can predict match outcomes, climb competitive leaderboards, and earn digital asset rewards seamlessly.

## Key Highlights
* **Native Telegram Experience:** Fast, responsive interface designed for quick match predictions without complex registration steps.
* **Dual-Chain Wallet Management:** Integrated support for both TON and Solana Web3 wallets, allowing users to connect their preferred ecosystem easily.
* **Live Market Oracle:** Real-time SOL/USD price tracking powered by Pyth Network integrated right inside the wallet dashboard for clear balance evaluation.
* **Automated Rewards:** Transparent reward and bonus mechanics leveraging Solana’s high-speed, micro-fee infrastructure.

## Tech Architecture
Built using modern web technologies (HTML5, CSS3, JavaScript) coupled with Supabase for secure data management, database policies, and real-time backend updates, integrated with Web3 SDKs and Pyth Network REST APIs.
